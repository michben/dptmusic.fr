# Import depuis ditto.fm

Ce dossier sert à l'import automatique (voir l'admin du site, bouton « Importer depuis ditto.fm »).

- `demande.json` : le lien à importer, déposé par l'admin. Il est supprimé une fois traité.
- `resultat.json` : le compte rendu du dernier import (réussi ou non).

Vous n'avez pas besoin de modifier ces fichiers à la main.
