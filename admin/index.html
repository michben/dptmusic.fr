Espace admin

Ajoutez et modifiez vos sorties sans toucher au code. Chaque enregistrement met à jour le site en 1 à 2 minutes.

Comment obtenir un jeton ? (à faire une seule fois)
  1. Connectez-vous sur GitHub, puis ouvrez github.com/settings/personal-access-tokens/new.
  2. Token name : « Admin site DPT ». Expiration : par exemple 1 an.
  3. Repository access : « Only select repositories » puis choisissez michben/dptmusic.fr. Attention : l’option par défaut « Public repositories » ne permet que de lire, et l’enregistrement échoue avec « Not Found ».
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur Generate token, copiez le jeton (il commence par github_pat_) et collez-le ci-dessus.

Le jeton reste uniquement dans votre navigateur. Ne le partagez avec personne.

Les sorties en haut de la liste s’affichent en premier sur le site et dans « Dernières sorties ».

Collez le lien de votre sortie : le titre, la pochette et les liens Spotify, YouTube, Deezer… sont récupérés automatiquement.

    Un champ laissé vide masque le bloc correspondant sur le site. Pour faire plusieurs paragraphes, laissez une ligne vide entre eux.

    Page « À propos »
    Mentions légales

    L’hébergeur et la propriété intellectuelle sont déjà écrits sur la page.

    Photo officielle

    Elle s’affiche sur l’accueil, sur la page « À propos » (sauf si vous y mettez une autre photo plus bas) et quand on partage le site. Elle est recadrée en carré et compressée automatiquement.

    Logo

    Il s’affiche en haut de toutes les pages. Un PNG à fond transparent donne le meilleur résultat ; la forme d’origine est conservée.

    Photo de la page « À propos »

    Facultatif : une autre photo que celle de l’accueil. Tant qu’aucune n’est choisie, la page « À propos » affiche la photo officielle.

    Icône du site

    La petite image dans l’onglet du navigateur et sur l’écran d’accueil des téléphones. Choisissez une image carrée et simple (par exemple votre logo seul) : elle est déclinée automatiquement dans toutes les tailles.

    Les pochettes se changent sur chaque sortie (onglet « Sorties » → « Modifier »). L’image affichée quand on partage le site sur les réseaux est la photo officielle.

    Laissez un champ vide pour masquer l’élément sur le site.
