Comment obtenir un jeton ? (à faire une seule fois)
  1. Connectez-vous sur GitHub, puis ouvrez github.com/settings/personal-access-tokens/new.
  2. Token name : « Admin site DPT ». Expiration : par exemple 1 an.
  3. Repository access : « Only select repositories » puis choisissez michben/dptmusic.fr.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur Generate token, copiez le jeton (il commence par github_pat_) et collez-le ci-dessus.

Le jeton reste uniquement dans votre navigateur. Ne le partagez avec personne.
